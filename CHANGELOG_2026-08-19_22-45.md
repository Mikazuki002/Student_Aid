### GitHub Pages Bug Fixes

#### Fixed Root Route 404 Issue
**Problem:** Visiting `https://mikazuki002.github.io/Student_Aid/` showed the application's 404 page instead of the home page, but clicking the "Home" button in the navbar worked correctly.

**Root Cause:** React Router's `BrowserRouter` expects a basename without a trailing slash, but Vite's `import.meta.env.BASE_URL` includes one (`/Student_Aid/`).

**Solution:**
- **File:** `src/main.tsx`
- **Change:** Modified basename from `import.meta.env.BASE_URL` to `import.meta.env.BASE_URL.replace(/\/$/, '') || '/'`
- **Result:** GitHub Pages root URL now correctly loads the home page

**Commits:**
- `6018182` - Fix GitHub Pages routing by adding basename to BrowserRouter
- `f6cfa5a` - Fix BrowserRouter basename to properly handle GitHub Pages root route

## Part 2: Platform Migration & CI/CD (v0.5.0)
**Time:** 21:00 - 22:45 UTC+08:00

### Platform Migration: GitHub Pages → Vercel

#### Why Migrate?
**GitHub Pages Limitations:**
- Base path complications (`/Student_Aid/` instead of `/`)
- Custom 404.html script required for SPA routing
- No automatic preview deployments for PRs
- Slower builds (~2 minutes)
- Manual custom domain setup

**Vercel Benefits:**
- Root path deployment (clean URLs)
- Built-in SPA routing (no custom scripts)
- Automatic preview deployments for PRs
- Faster builds (~60 seconds)
- Automatic SSL + DNS for custom domains
- Environment variable support

#### Migration Changes

##### 1. Build Configuration
**File:** `vite.config.ts`

**Before:**
```typescript
const repoBase = '/Student_Aid/'
export default defineConfig(({ command }) => ({
  plugins: [react()],
  base: command === 'build' ? repoBase : '/',
}))
```

**After:**
```typescript
export default defineConfig({
  plugins: [react()],
  base: '/',
})
```

**Impact:** Simplified configuration, always uses root path.

##### 2. Router Configuration
**File:** `src/main.tsx`

**Before:**
```typescript
const basename = import.meta.env.BASE_URL.replace(/\/$/, '') || '/'
<BrowserRouter basename={basename}>
```

**After:**
```typescript
<BrowserRouter>
```

**Impact:** No basename logic needed, cleaner code.

##### 3. SPA Routing
**File:** `index.html`

**Removed:** ~25 lines of GitHub Pages SPA fallback restoration script
```javascript
// Deleted the entire inline <script> that parsed ?p= query parameters
```

**Impact:** Cleaner HTML, Vercel handles SPA routing natively.

**File:** `public/404.html`

**Action:** **DELETED**

**Reason:** Vercel doesn't need custom 404.html for SPA routing.

##### 4. Sitemap Configuration
**File:** `scripts/generate-sitemap.js`

**Before:**
```javascript
const baseUrl = 'https://mikazuki002.github.io/Student_Aid'
```

**After:**
```javascript
const baseUrl = process.env.VITE_SITE_URL || 'https://student-aid-support-group.vercel.app'
console.log(`   Base URL: ${baseUrl}`)
```

**Impact:** Configurable via environment variable, works with any domain.

**File:** `public/robots.txt`

**Before:**
```
Sitemap: https://mikazuki002.github.io/Student_Aid/sitemap.xml
```

**After:**
```
Sitemap: /sitemap.xml
```

**Impact:** Relative URL works with any domain.
